## 什么是二分法？

在 Socionics 中，二分法（Dichotomy）是将整个类型学空间一分为二的分类方式。每一组二分法定义了一对互斥的特质（poles），每个 TIM 在每个二分法上占据其中一个极端。二分法构成了 Socionics 中最基础的分类框架。

奥古斯塔将二分法分为三个层级：

| 层级 | 名称 | 二分法数量 | 适用范围 |
|------|------|-----------|---------|
| **第一层** | 元素二分法 + 功能二分法 | 6 + 7 = 13 组 | 分别适用于 IME 和功能位置 |
| **第二层** | 荣格基础（Jungian Foundation） | 4 组 | 适用于 TIM（类型） |
| **第三层** | 赖宁二分法（Reinin Dichotomies） | 15 组（含荣格4组） | 适用于 TIM（类型） |

## 三大二分法体系的区别

### 1. 信息代谢元素二分法（6 组）

这些二分法适用于**八个 IME**，将它们分为各含四个元素的互斥群体。它们描述了 IME 本身的内在属性：

| 二分法 | 分组 | 核心问题 |
|--------|------|---------|
| 外倾 / 内倾 | Ne/Fe/Se/Te vs Ni/Fi/Si/Ti | 关注对象本身还是对象间的关系？ |
| 逻辑 / 伦理 | Ti/Te vs Fi/Fe | 关注客观规律还是主观价值？ |
| 直觉 / 感觉 | Ne/Ni vs Se/Si | 关注潜在可能性还是当前现实？ |
| 理性 / 非理性 | Ti/Fi/Te/Fe vs Ne/Ni/Se/Si | 评判/决策还是感知/接收？ |
| 静态 / 动态 | Ne/Se/Ti/Fi vs Ni/Si/Te/Fe | 静止状态还是变化过程？ |
| 显性 / 隐性 | Se/Si/Te/Ti vs Ne/Ni/Fe/Fi | 信息是直接可见的还是隐含推断的？ |

> **来源**：奥古斯塔《论人类的二重性》，主要基于荣格《心理类型》的四个基础二分法，并扩展了静态/动态和显性/隐性。

---

### 2. 功能位置二分法（7 组）

这些二分法适用于模型A中的**八个功能位置**（主导、创造、角色……），描述了功能如何在信息代谢机制中运作：

| 二分法 | 分组（功能位置编号） | 核心问题 |
|--------|---------------------|---------|
| 意识 / 生机 | 1-2-3-4 vs 5-6-7-8 | 有意识处理还是无意识处理？ |
| 输入 / 输出 | 1-3-5-7 vs 2-4-6-8 | 感知接收信息还是创造输出信息？ |
| 运动 / 潜能 | 1-2-7-8 vs 3-4-5-6 | 强而果断还是弱而迟疑？ |
| 重视 / 非语言 | 1-2-5-6 vs 3-4-7-8 | 可公开讨论还是集体行动领域？ |
| 引导 / 分离 | 1-4-5-8 vs 2-3-6-7 | 持续评估还是情境适应？ |
| 惰性 / 接触 | 1-4-6-7 vs 2-3-5-8 | 独立积累还是依赖外部影响？ |
| 大胆 / 谨慎 | 1-3-6-8 vs 2-4-5-7 | 自由表达还是谨慎克制？ |

> **来源**：奥古斯塔《雷宁二分法理论》，基于模型A的结构特性推导。

---

### 3. 赖宁二分法（15 组）

1984 年，俄罗斯数学家格里高利·雷宁（Grigoriy Reinin）通过数学证明，基于四组荣格基础二分法（外倾/内倾、感觉/直觉、逻辑/伦理、理性/非理性），可以推导出共 **15 组正交二分法**。这 15 组包含 4 组荣格基础 + 11 组衍生二分法。

赖宁二分法适用于**十六种 TIM**，每组的 8 个类型共享该二分法的某一极。

奥古斯塔在《雷宁二分法理论》中将这 15 组二分法按**二元化的四个阶段**进行了组织：

| 二元化阶段 | 包含的赖宁二分法 | 所属层级 |
|-----------|-----------------|---------|
| **阶段1：潜能基础** | 1. 外倾/内倾 + 2. 静态/动态 | 对偶二分法 |
| **阶段2：调动** | 3. 询问/声明 + 4. 积极/消极 | 对偶二分法 |
| **阶段3：程序** | 5. 直觉/感觉 + 6. 逻辑/伦理 | 对偶二分法 |
| **阶段4：实施** | 7. 战术/战略 + 8. 建构/情感 | 对偶二分法 |
| **四象限阶段1** | 9. 左/右（过程/结果） | 四象限二分法 |
| **四象限阶段2** | 10. 理性/非理性 | 四象限二分法 |
| **四象限阶段3** | 11. 顺从/顽固 + 12. 无忧/远见 | 四象限二分法 |
| **四象限阶段4** | 13. 民主/贵族 | 四象限二分法 |
| **社会人阶段1** | 14. 欢乐/严肃 | 社会人二分法 |
| **社会人阶段2** | 15. 审慎/决定性 | 社会人二分法 |

> ⚠️ **诚实提醒**：赖宁二分法在 Socionics 社区中存在显著争议。许多实践者（包括古连科本人）对第5组以外的赖宁二分法的实际有效性持保留态度。奥古斯塔本人也只提供了初步描述，且明确指出她的描述是"匆忙修订的版本"。在回答用户时应诚实告知这些争议。

## 赖宁二分法的四个层级

奥古斯塔在《雷宁二分法理论》中将这 15 组二分法组织为四个层级，对应信息代谢从个体到社会的四个整合层次：

### 第一层：对偶二分法（Dual Dichotomies）—— #1 到 #8

- 在对偶（Duals）之间**不共享**（互补）
- 共 8 组：外倾/内倾、静态/动态、询问/声明、积极/消极、直觉/感觉、逻辑/伦理、战术/战略、建构/情感

### 第二层：四象限二分法（Quadra Dichotomies）—— #9 到 #12

- 在对偶之间**共享**，在不同 Quadra 之间区分
- 共 4 组：左/右、理性/非理性、顺从/顽固、无忧/远见

### 第三层：社会人二分法（Socion Dichotomies）—— #13 到 #15

- 在 Quadra 之间**共享**，将社会人分为两半
- 共 3 组：民主/贵族、欢乐/严肃、审慎/决定性

### 第四层：社会进步环（Rings of Social Progress）

- 奥古斯塔将 8 个对偶二分体组织为两个社会进步环（左环和右环），每个环内信息沿单向流动
- 详见 `reinin/06-quadra-stage1.md` 和 `09-relations.md`

## 二分法组合表

奥古斯塔在《雷宁二分法理论》末尾提供了一个"二分法组合"表，展示了以下二分法组合如何叠加形成模型A的各个块和功能位置：

- 意识/生机 + 输入/输出 → 四个水平块（自我、超我、超本我、本我）
- 运动/潜能 + 引导/分离 → 四个维度层级（1D-4D）
- 重视/非语言 + 加速/减速 → Quadra 价值观
- 惰性/接触 + 大胆/谨慎 → 功能的行为特征

这些组合表明：二分法并非孤立存在，而是通过叠加形成更复杂的结构。完整的组合表参见 `reinin/12-summary-tables.md`。
