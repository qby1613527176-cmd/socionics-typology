# SCS 判型指标——模块、二分法与 IME± 指标 (SCS Indicators: Blocks, Dichotomies & Charged IMEs)

> 本文件收录 SCS 学派判型指标体系中的**模块指标**（超我/超本我/本我/自我）、**二分法指标**（意识/生机、输入/输出、重视/非重视、引导/分离、惰性/接触）以及**信息元素正负指标**（±IME）。
>
> 原文处于 Alpha / 持续修订阶段。依据《SCS Indicators》原文结构整理；中文用词参照站内既有译文统一。部分指标描述由知乎版补充。
>
> 模块理论详解请参见 [`../02-model-a/`](../02-model-a/)；电荷系统详解请参见 [`../06-charges/`](../06-charges/)。

## 一、模块指标

模块指标用于识别信息代谢元素位于模型 A 的哪个模块（超我/自我/超本我/本我）。

### 超我模块（Super-Ego）

| 指标 | 描述 |
|------|------|
| `IND SE-A` | 注意到某个领域中的广泛问题，但不提供具体的解决方案。 |
| `IND SE-B` | 试图使自己符合社会期望，即使个体对自己所处的状态没有信心。 |
| `IND SE-C` | 试图不突出自己，融入并避免在该领域被看到。 |

### 超本我模块（Super-Id）

| 指标 | 描述 |
|------|------|
| `IND SI-A` | 渴望外部纠正和／或批准。 |
| `IND SI-B` | "炫耀"，以一种自夸和夸张的方式。 |
| `IND SI-C` | 将所面临的问题归咎于他人（或世界），即使个体对此负责。 |

### 本我模块（Id）

| 指标 | 描述 |
|------|------|
| `IND ID-A` | 遵循社会规划。 |
| `IND ID-B` | 努力成为他人的榜样。 |
| `IND ID-C` | "炫耀"，带有自信和毫不费力的迹象。 |

### 自我模块（Ego）

| 指标 | 描述 |
|------|------|
| `IND EG-A` | 自信地提出具有细微差别的论点的观点。 |
| `IND EG-B` | 宣布解决当前标准问题的新的规范或存在方式。 |

## 二、意识—生机指标

意识环功能（位置 1-4）通过有意识的思考处理信息；生机环功能（位置 5-8）以无意识的、自动化的方式处理信息。

### 生机（Vital）

| 指标 | 描述 |
|------|------|
| `IND VT-A` | 答案听起来像是对过去的模糊回忆：事情"通常"如何或他们"有时"如何发生。 |
| `IND VT-B` | 自动化。个体潜意识地根据这些信息行事，并且只有在事后才会意识到。 |
| `IND VT-C` | 习惰性。个体按照这些信息中的习惯行事，而没有意识到。 |
| `IND VT-D` | 没有感觉在思考或推理信息——缺乏对它的关注。 |
| `IND VT-E` | 信息自发地或意外地显现出来。 |
| `IND VT-F` | 个体只对信息如何影响自己感兴趣；不关心社会如何看待它。 |
| `IND VT-G` | 虽然个体可能有个人规范，但他们不知道社会如何看待信息。 |
| `IND VT-H` | 个体凭直觉行事：他们不计划或预先考虑他们的行动。 |
| `IND VT-I` | 信息正在传达一个人的身体功能/生机状态。 |
| `IND VT-J` | 个体只能通过行动理解元素，而无法用语言解释。 |

### 意识（Mental）

| 指标 | 描述 |
|------|------|
| `IND MN-A` | 思考回答问题的时候大声的说出来，有意识的思考这个问题。 |
| `IND MN-B` | 在回答问题的时候使用反问修辞。 |
| `IND MN-C` | 以社会或者人民的名义说话。标记词包括"我们"，"人们"。 |

> 注（原文附）：仅仅使用这些标记词并不能代表这条意识——在回答"人们是否通常这样"时说"我们"，不能计为 MN-C。
| `IND MN-D` | 提到社会观点看法时，意识到关于社会态度信息。 |
| `IND MN-E` | 深思熟虑的考虑行为和行动。 |
| `IND MN-F` | 意识到人们是如何看待和回应他们自身行为的。 |
| `IND MN-G` | 说教，或者社会评论。 |
| `IND MN-H` | 经常反思和观察别人或者自己。 |

### 个体性（Individuality）

| 指标 | 描述 | 附加标记 |
|------|------|---------|
| `IND IN-A` | 强调被访者个性化的观点和想法——比如"这就是我的想法"，"对我来说，这是我的个性"。 | 个体性 (生机 or 1D) |

## 三、输入—输出指标

输入功能（接受性元素，位置 1/3/5/7）识别问题；输出功能（生产性元素，位置 2/4/6/8）解决问题。

### 输出（Producing）

| 指标 | 描述 |
|------|------|
| `IND PR-A` | 信息本身没有实体，通过事物联系和构建假象。 |
| `IND PR-B` | 谨慎，适应他人对于信息的观点，而不是认为自己的看法是正确的。 |
| `IND PR-C` | （原文未提供描述） |

### 输入（Accepting）

| 指标 | 描述 |
|------|------|
| `IND AC-A` | 认为信息是已经存在的，是世界和现实的一部分。 |
| `IND AC-B` | 信息本身就是一个目标。有意于在这个领域进行竞争。 |

## 四、重视—非重视指标

重视功能（位置 1/2/5/6）被个体认真对待并主动使用；非重视功能（位置 3/4/7/8）仅在情境要求时使用。

### 非重视（Non-Valuing）

| 指标 | 描述 |
|------|------|
| `IND NV-A` | 严肃的对待，不是开玩笑的时候。 |
| `IND NV-B` | 仅仅展现信息如何发生，不掺杂个人理解。 |
| `IND NV-C` | 允许别人干预。集体完成任务。 |
| `IND NV-D` | 保密，不愿意展现隐藏领域信息。 |
| `IND NV-E` | 认为没有权力去评论和批判。 |

### 重视（Valuing）

| 指标 | 描述 |
|------|------|
| `IND VR-A` | 开放的讨论，愿意用玩笑的方式来评论信息。 |
| `IND VR-B` | 不想干预别人，也不想被别人干预，所以都是单独的完成实践。 |

---

## 五、引导—分离指标

引导功能做出强烈判断，持续评估；分离功能根据具体情境进行判断，判断是间歇性的。

### 分离（Situational）

| 指标 | 描述 |
|------|------|
| `IND SL-A` | 慎重处理，信息都是经过深思熟虑的。 |
| `IND SL-B` | 不关心完美主义，并且有随意性的倾向。 |
| `IND SL-C` | 并不希望受到评价，并且批判他人。 |

### 引导（Evaluatory）

| 指标 | 描述 |
|------|------|
| `IND EV-A` | 稳定的处理，个体总是连续不断地学习。 |
| `IND EV-B` | 完美主义，总是尽可能的做到最好。 |
| `IND EV-C` | 评论他人和期望得到评论。 |

## 六、惰性—接触指标

惰性功能（位置 1/4/6/7）类似于人的内脏器官，较为静态和固执；接触功能（位置 2/3/5/8）类似于人的表皮四肢，是外界能碰着、也愿意用来碰外界的功能。

### 接触（Contact）

| 指标 | 描述 |
|------|------|
| `IND CT-A` | 对于帮助别人，得到荣誉和感谢感兴趣。 |
| `IND CT-B` | 适应性，能够在情境中快速的做出改变。 |
| `IND CT-C` | 喜欢在"可靠的"信息来源工作，避免一些可疑的，没有确定的。 |

### 惰性（Inert）

| 指标 | 描述 |
|------|------|
| `IND IT-A` | 顽固，倾向于用"模式"去理解信息，而不是快速的更新。 |
| `IND IT-B` | 理解新事物很慢。 |
| `IND IT-C` | 喜欢在未知消息来源中工作，总是能"找到自我"。 |

> 注：`IND IT-B` 和 `IND IT-C` 的描述由知乎版《SCS 判型指标》补充，主站版本中缺失。

## 七、信息元素正负指标（±IME）

每个信息代谢元素（IME）分为正（+）和负（−）两种"电荷"变体，描述同一元素在信息处理时的内在方向和质量偏向。以下为每个 ±IME 的指标描述。

### Ne（外倾直觉）

| 电荷 | 名称 | 描述 |
|------|------|------|
| `+Ne` | 新角度的直觉 (Intuition of Novelty) | 看到事物的能力，将不可能变为可能。为了更好的突破，用新的结构去 highlight 特定的本质。 |
| `-Ne` | 潜在的直觉 (Intuition of Latency) | 意识到现有的能力，去重新组建已经建立好的结构，highlight 一般的人类现象。 |
| `+Ne` | 发展的直觉 (Intuition of Development) | 从头开始发展潜力，从学徒到大师，发展其他人不具备的技能。 |
| `-Ne` | 天赋的直觉 (Intuition of Talent) | 发展现在个体身上具备的天赋，为了避免"浪费潜力"。Highlight 个体的独特之处。 |

### Se（外倾感觉）

| 电荷 | 名称 | 描述 |
|------|------|------|
| `+Se` | 消费感官 (Sensorics of Expenditure) | 为了投资新事物，在新的事物上花费大量金钱，将资源变得对自己的提升有用。 |
| `-Se` | 节省感官 (Sensorics of Conservation) | 节约金钱，将钱财放在值得的地方。 |
| `+Se` | 可见的感官 (Sensorics of Visibility) | 为了引起人们的注意力，让事物变得可见。优雅的装扮，并且能够在聚光灯下工作。 |
| `-Se` | 不可见感官 (Sensorics of Invisibility) | 为了将事物从人们的注意力中移开，让事物变得不可见。安静的着装，并且能够在阴影中工作。 |

### Te（外倾逻辑）

| 电荷 | 名称 | 描述 |
|------|------|------|
| `+Te` | 加速逻辑 (Logic of Acceleration) | 快速的工作，一次性完成大量工作，精力全部爆发，然后消耗殆尽。 |
| `-Te` | 稳定逻辑 (Logic of Steadiness) | 稳定且缓慢的行动，并且逐渐的完成，逐步的从行动中过渡。 |
| `+Te` | 结果逻辑 (Logic of Results) | 为了能够达成最终目标，能够有效的完成任务。 |
| `-Te` | 过程逻辑 (Logic of Processes) | 为了能够重复利用过程，保证每个阶段的正确。需要验证方法，保证其可循环性。 |

### Fe（外倾伦理）

| 电荷 | 名称 | 描述 |
|------|------|------|
| `+Fe` | 积极情感的伦理 (Ethics of Positive Emotions) | 总是关注积极情绪，激励人们加油，兴奋起来，抖擞意识，并让人意识焕发。 |
| `-Fe` | 消极情感的伦理 (Ethics of Negative Emotions) | 总是关注消极情绪，去赞赏负面情绪的美丽。 |
| `+Fe` | 强烈感情的伦理 (Ethics of Intensity) | 输入激烈，充满热情的感情。 |
| `-Fe` | 调和情感的伦理 (Ethics of Conciliation) | 平衡他人的情绪，缓解人们的负面情绪。 |

### Ni（内倾直觉）

| 电荷 | 名称 | 描述 |
|------|------|------|
| `+Ni` | 希望的直觉 (Intuition of Hope) | 看到光明和美好的未来，对美好的事物充满希望。 |
| `-Ni` | 冒险的直觉 (Intuition of Jeopardy) | 为了能够看到危险，并且对其他人发出警告。 |
| `+Ni` | 仓促的直觉 (Intuition of Haste) | 快速的感觉时间，在时间流逝中体验。 |
| `-Ni` | 节奏的直觉 (Intuition of Pacing) | 计划，组织，并保持生活中一贯的节奏。 |

### Si（内倾感觉）

| 电荷 | 名称 | 描述 |
|------|------|------|
| `+Si` | 舒适的感官 (Sensorics of Comfort) | 为了保持积极性。需要将注意力放在让自己感到舒适的地方。尽可能的让自己感受到积极性。 |
| `-Si` | 不适感官 (Sensorics of Discomfort) | 为了认清自己消极的情感。并且努力消除这种情感。 |
| `+Si` | 放纵感官 (Sensorics of Indulgence) | 顺从内心最真实的感受，享受当下的美好。 |
| `-Si` | 节制感官 (Sensorics of Temperance) | 认知自己内心最真实的感受。合理节制自己。 |

### Ti（内倾逻辑）

| 电荷 | 名称 | 描述 |
|------|------|------|
| `+Ti` | 互相依靠的逻辑 (Logic of Interdependence) | 为了提高在社会连接中的链接，相互合作，互相扶持。 |
| `-Ti` | 独立的逻辑 (Logic of Independence) | 为了能够减少自身需求，将自己的需求和他人分离开来。 |
| `+Ti` | 建设的逻辑 (Logic of Construction) | 为了建立连接，提升价值，完成自我的进化。 |
| `-Ti` | 解构的逻辑 (Logic of Deconstruction) | 为了打破某个联系，为了寻求公正，为了推翻旧的权威。 |

### Fi（内倾伦理）

| 电荷 | 名称 | 描述 |
|------|------|------|
| `+Fi` | 原谅的伦理 (Ethics of Forgiveness) | 为了看到缺点，原谅曾经犯错的人。 |
| `-Fi` | 谴责的伦理 (Ethics of Condemnation) | 为了不再去原谅那些犯过错的人，把那些人应该收到的惩罚加倍反馈回去。 |
| `+Fi` | 亲密的伦理 (Ethics of Closeness) | 为了能够靠近对方，为了能够表达爱。 |
| `-Fi` | 疏远的伦理 (Ethics of Distance) | 为了避免过近的距离，减少交流。 |
