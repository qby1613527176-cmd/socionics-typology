# SCS 判型指标（SCS Indicators）——导航与概览

本目录收录 SCS 学派的**判型指标体系**——一套带编号的行为指标目录，用于从访谈文本中识别信息代谢元素（IME）及其维度、模块、二分法归属。

依据《SCS Indicators》原文结构整理；中文用词参照站内既有译文统一。原文处于 Alpha / 持续修订阶段。

| 文件 | 内容 | 体量 |
|------|------|------|
| `01-dimension-indicators.md` | 维度相关指标：体验(EX) · 一维(1D) · 低维(LD) · 规范(NR) · 情境(ST) · 高维(HD) · 时间(TM) · 主导(F1) | 中等 |
| `02-block-dichotomy-indicators.md` | 模块指标(超我/超本我/本我/自我) + 二分法指标(意识/生机 · 输入/输出 · 重视/非重视 · 引导/分离 · 惰性/接触) + IME±指标 | 中等 |
| `03-typing-practice.md` | 新手判型实例题（5组测试 + 答案）——判型能力练习 | 中等 |

## 如何使用判型指标

1. **先理解维度理论**：阅读 `../08-dimensions/` 了解 1D-4D 四维度（经验/规范/情境/时间）的含义
2. **对照指标识别**：在访谈文本中寻找与各指标匹配的行为表现
3. **交叉验证**：同一功能应同时在维度指标、模块指标和二分法指标中呈现一致性
4. **注意电荷**：高维/低维功能可能伴随控制情绪（±号标记），参见 `../06-charges/`
5. **完整判型执行**：当用户提交问卷/访谈文本并要求判型结论时，按 [`../19-typing-workflow.md`](../19-typing-workflow.md) 的七层流水线执行——判型结论必须附带反证清单与置信度

## 符号说明

- `IND` = Indicator（指标）
- `EX` = Experience（体验/经验维度）
- `1D` = 一维性
- `LD` = Low Dimensional（低维度）
- `NR` = Normative（规范维度）
- `ST` = Situational（情境维度）
- `HD` = High Dimensional（高维度）
- `TM` = Time（时间维度）
- `F1` = Leading function（主导功能）
- `SE` = Super-Ego（超我模块）
- `SI` = Super-Id（超本我模块）
- `ID` = Id（本我模块）
- `EG` = Ego（自我模块）
- `VT` = Vital（生机环）
- `MN` = Mental（意识环）
- `PR` = Producing（输出）
- `AC` = Accepting（输入）
- `VR` = Valuing（重视）
- `NV` = Non-Valuing（非重视）
- `EV` = Evaluatory（引导）
- `SL` = Situational/Separating（分离）
- `CT` = Contact（接触）
- `IT` = Inertia（惰性）
