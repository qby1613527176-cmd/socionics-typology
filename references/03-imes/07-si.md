# 内向感觉 / 感官（Introverted Sensing — Si）

**符号**：![Si]　　**宏观元素**：感觉　　**态度**：内倾　　**理性/非理性**：非理性　　**静态/动态**：动态　　**显性/隐性**：显性

> 感觉这一宏观元素被定义为<空间>的基础方面，分为外向感觉（Se）与内向感觉（Si）。该宏观元素关注累计的运动力量、空间中对象的同时交互，以及舒适感和对象形状的特性。Si 特别涉及空间中同时发生的过程间的相互作用——即一个对象如何在另一个对象中得到反映，以及由此产生的身体感受。

---

## 一、正式定义（两套来源）

### 来源一：奥古斯塔《论人类的二重性》

**同时发生过程之间的关系——空间。** 通过此元素，个体获得关于空间性质的信息，即空间中发生了什么及空间内人们的感受。

> **注**：在奥古斯塔关于 Si 定义的翻译中，短语"个人的感受"及"状态"均为俄语"самочувствие"的对应表达。该词无法完全翻译，定义为"个体在任一时刻身心状态的一般心理指标；由特定感觉与整体情感构成"。

### 来源二：奥古斯塔《socionics中使用符号的含义》

**状态。** 对象在其他对象中的内部状况，以及其他对象如何影响并反映于该对象的状态。你可以将其称为对象内部空间的"回响"。状态由外部和内部过程共同决定。

对某事是否愉悦的感觉，以及生理和审美上的满足与不满。

## 二、完整描述

**内倾-感知型-非理性-动态-显性**

**状态。对对象内部情境的知觉。**

**同时发生过程之间的关系——空间。** 个体通过该元素接收关于空间性质的信息，即空间内发生的事物及人们在该空间中的感受（包括身体和精神层面）。

对象在其他对象中的内部状态，其他对象如何影响该对象状态并反映于此。这可以被描述为对象内部空间的"共鸣"。状态由外部和内部过程共同决定。

愉悦感、生理及美学上的满足或不满。

我们将对象的内部状态视为相互影响的事件之间的关系。通过该元素，信息被知觉为过程如何影响内部状态：个体如何体验当下瞬间，以及由这种相互依赖引发的具体情绪。

空间中的互动不过是一个对象在另一个对象中的反映。对象相互反映，并互相引发特定的情绪。个体将直接的外部信息知觉为由周围事物发生所触发的情绪。例如，疼痛的感觉仅是大脑对身体与某处正在干扰其功能的过程之间关系的反映。

当该知觉方面占据主导时，个体能够改变环境的属性及环境中人们的感受。他们知道如何避免身体不适感，并保护他人免受其害，这种能力取决于再现曾经经历过的美学感受的能力。一个极其典型的例子是彼得·保罗·鲁本斯，他并非凭借当下生活场景作画，而是凭借过去美学感受的记忆。在创作画作时，他力图通过再现这种美学感受，赋予观者特定的审美体验。这种艺术是对象的复活，向观者传达创作者所意图的美学感受。同样，具有此类型知觉的个体在烹饪时，会先想象菜肴的味道。这些人能够区分过去与新的审美感受，并懂得如何收集与记忆它们。这大概解释了为何所谓"心理诊断师"中有许多此类类型的个体。

具备此类型知觉的个体，可以将自身的审美感官需求与他人的同类需求进行对比。他们懂得如何努力满足这类需求，且能塑造和提升自己及他人的审美趣味与习惯。他们具备将自身对美学及舒适生活理解强加于他人的能力。

## 四、符号化定义

**➢ 关系的显性动态 —— 对对象之间直接可观察关系变化（如因果关系）的知觉。**

**➢ 接收关于同时发生过程之间关系——空间的信息。关于空间的属性，即空间中发生的事物以及其中人们的感受。**

---

## 五、关于 Si 的信息

利用此元素，感知到的是关于对象之间空间关系中的以下方面信息：

➢ 我们视为条件相互关联的事件之间关系的对象内部状态。通过此元素，人们感知过程如何影响内部状态——人的感受，以及这种相互依赖所引发的具体情感。

➢ 空间在对象内部的"回响"现象。状态由外部和内部过程共同决定。

➢ 对事物是否愉悦的感知，以及身体和审美上的满足与不适感。

➢ 空间中发生的事物及人们在该空间中的感受（包括身体和精神层面）。

➢ 对象在其他对象中的内部情境——即其他对象如何影响该对象的状态并反映于此。

---

## 六、利用此元素，个人可以

当内向感觉（Si）处于主导或创造位置时，个体具备以下核心能力：

➢ 改变环境属性及其中人们的感受。

➢ 如何避免身体不适以及如何保护他人免受其害，这取决于再现既有审美感受的能力。

➢ 将自身感官审美需求置于与他人相同需求的对立面。

➢ 为满足上述需求而斗争。

➢ 形成并完善自身及他人的审美趣味与习惯。

➢ 将其对美学与舒适生活的理解强加于他人。

➢ 重现曾经经历过的美学感受——如画家凭记忆创作、厨师凭想象调味。

➢ 区分过去体验过的审美感受与新的审美感受，并有意识地收集和记忆它们。

➢ 察觉环境中的不适因素并主动消除它们。

## 七、Si 在不同功能位置的表现

| 位置 | 类型 | Si 的表现 |
|------|------|----------|
| **主导 (1)** | SEI, SLI | 最自觉、最自信的感官能力。深刻感知身体状态和环境舒适度。享受生活的简单乐趣。天生的"舒适创造者"和"美食品鉴家"。以身体感觉作为决策和世界观的基础 |
| **创造 (2)** | ESE, LSE | 创造性地运用感官体验来服务他人。为他人营造舒适和愉悦的环境。以物质和感官的方式表达关怀。懂得如何用美食、舒适的空间和贴心的礼物来取悦他人 |
| **角色 (3)** | IEI, ILI | 适应社会对舒适和健康的期望。关注时尚和外观，保持整洁，但非内在驱动。遵守社会的健康和卫生规范。容易过度关注身体症状（IEI）或过度节俭（ILI） |
| **脆弱/PoLR (4)** | EIE, LIE | 最薄弱的区域。对身体不适和健康问题深感焦虑。害怕生病和身体痛苦。难以戒除坏习惯。对外观的批评极其敏感。在性方面常表现出极端差异——从冷漠到变态 |
| **暗示 (5)** | ILE, IEE | 完全依赖外部的舒适照顾。不知如何照顾自己的身体和健康。渴望有人为其营造舒适的环境。若无对偶关怀，可能显得邋遢或忽视自身健康 |
| **激活 (6)** | LII, EII | 需要外部鼓励来照顾自己的身体和舒适。在支持性环境中能学会享受感官愉悦。对身体感受的批评敏感。可被对偶编程——学习如何放松和享受生活 |
| **观察/忽略 (7)** | SLE, SEE | 能力强但不重视。能感知身体状态和舒适度但选择性关注。在为重大目标奋斗时忽视身体疲劳和饥饿。在需要时能展示惊人的身体耐力 |
| **演示 (8)** | LSI, ESI | 强大且展示性。展示令人惊讶的感官管理能力。以"你看，我也能享受生活"的方式展示对身体舒适的把控。在关键时刻能以极简条件保持良好状态，并以此自豪 |

## 九、Si 的电荷（±）变体

| 电荷 | 特性 | 所属类型 |
|------|------|---------|
| **Si+（舒适感觉学/放纵感觉学）** | 培养积极感受，关注舒适度，努力增加自身体验的积极情感，使空间舒适且愉悦。顺应自然本能，屈从诱惑，最大化强烈的积极感受，做令自己感觉良好的事 | ESE, LII, SLE, IEI, LIE, ESI, IEE, SLI |
| **Si-（不适感觉学/节制感觉学）** | 识别消极感受，关注痛苦，努力消除自身体验的负面情感，从空间中移除不需要的事物。控制冲动，识别诱惑，即使在放纵时也调节自身的消耗 | ILE, SEI, EIE, LSI, SEE, ILI, LSE, EII |

**Si+ 的具体表现**：
- 倾向于培育积极感觉，关注舒适感，并提升身心体验的愉悦度
- 主动创造舒适愉悦的空间，增强感官体验，并遵循自然本能以获得良好感受
- 关注如何布置空间以输出愉悦效果，或他人如何以放松、和谐与关怀回应其内部状态
- 顺应自然本能，屈从诱惑，最大化强烈的积极感受，做令自己感觉良好的事
- SLI 追求和平与放松，厌恶紧张与冲突
- ESE 极力提升舒适与健康，投入大量精力创造额外便利

**Si- 的具体表现**：
- 识别并对不适感、疼痛及不受欢迎的刺激做出反应，进而采取行动予以消除或减轻
- 注意力集中于识别当前情境何时不当，感觉何时不适，以及内部环境何时需调整
- 调节并防护以防止失衡输出——不创造舒适感，而是修正不舒适
- 非为追求快感，而是节制放纵，控制消费，识别诱惑并采取行动防止过度
- SEI 寻求强烈的情绪，倾向于对立口味的组合输出吸引
- LSE 致力于最小化不适感，不畏长期不便，能够克服疾病

## 十、在模型G中的对应

在古连科的模型G / SHS 学派中，Si 的电荷分为：

- **S+（舒适感）**：调整环境，使其尽可能舒适，充分利用所有可用的舒适条件。使你的领地自给自足，如同智能家居。一种健康感或统一满足口味的感受，可能变得单调，寻求统一的自动妥协。放松而柔和的感受，最大化舒适度。SLI 追求和平与放松，厌恶紧张与冲突。ESE 极力提升舒适与健康，投入大量精力创造额外便利。

- **S-（不适感的感知）**：解决日常不适感。治疗疾病。在口味和环境的极端之间寻求平衡，追求极端之间的合理妥协（调解）。敏锐、充满活力且对比强烈的感受，旨在最小化不适感。SEI 寻求强烈的情绪，倾向于对立口味的组合输出吸引。LSE 致力于最小化不适感，不畏长期不便，能够克服疾病。

## 十一、Si 与其他 IME 的关联

### Si 与 Se（外倾感觉）

Si 关注对象**内部的**感受状态——"我感觉如何？这里舒适吗？"；Se 关注对象**外在的**形态和力量——"谁更强？这看起来好吗？"。Si 是"被空间影响"——身体被动地接收环境的回响；Se 是"影响空间"——主动地施加意志改变环境。Si 追求内在的和谐与平衡，Se 追求外在的控制与征服。

### Si 与 Ni（内倾直觉）

Si 和 Ni 都是内倾的动态非理性元素，都涉及过程间的关系——但 Si 涉及**同时**发生的过程间关系（空间感、身体感受），而 Ni 涉及**按时间顺序**发生的过程间关系（时间感、趋势预测）。Si 是"此刻的状态"，Ni 是"时间的流动"。Si 感知空间的和谐与不和谐，Ni 感知事件序列的节奏与走向。

### Si 与 Fe（外倾伦理）

在 Alpha Quadra（ILE, SEI, ESE, LII）中，Si 与 Fe 协作——身体的舒适和愉悦（Si）为积极的情绪氛围（Fe）提供基础。SEI 以美食和舒适环境营造温暖的社交氛围。ESE 以身体上的关怀和照顾来表达和激发正向情绪。Si 提供"感到舒适"，Fe 提供"感到快乐"。

### Si 与 Te（外倾逻辑）

在 Delta Quadra（LSE, EII, IEE, SLI）中，Si 与 Te 协作——身体的舒适和健康（Si）是高效工作（Te）的前提和目的。LSE 以优化工作方法来改善生活质量。SLI 以最小的努力创造出最大的舒适。Si 提供"什么是好的生活"，Te 提供"如何实现好的生活"。

## 十二、空间的回响——Si 的特有领域

奥古斯塔特别强调 Si 处理的是对象内部空间的"**回响**"（resonance）：

- 每个对象在空间中与其他对象共存。当其他对象发生运动和变化时，这些变化在对象内部得到"反映"——就像声波在封闭空间中产生回音
- 对人而言，这种"内部回响"体现为**身体的感觉**——温暖、寒冷、疼痛、愉悦、紧张、放松
- Si 感知的不是对象本身，而是对象所处空间中各对象之间的相互作用对该对象内部状态的影响
- 这也解释了为何 Si 类型能"重现曾经体验过的审美感受"——他们在身体记忆中储存了特定空间配置所引发的特定感觉

**具体示例**：
- 一个人走入一个刚发生过争吵的房间，尽管争吵已经结束，房间的"氛围"仍然留存——Si 感知的就是这种空间的"残留回响"
- 一位厨师在烹饪前先想象菜肴的味道——他在调用记忆中存储的特定食材组合在口腔空间中产生的感官回响
- 一位画家凭记忆而非现场作画——他在调取曾经特定场景在自己身体内部产生的审美回响，并将其转化为画布上的视觉回响
