# 学派差异对比表（School Differences）

## 符号说明

| 符号 | 含义 |
|------|------|
| `—` | 该学派未对该现象的归属给出明确定义 |
| `Xe` | 泛外倾（未指定具体外倾元素） |
| `Xi` | 泛内倾（未指定具体内倾元素） |
| `Sx` | 感觉泛型（未指定具体感觉元素，即 Se 或 Si） |
| `Tx` | 逻辑泛型（未指定具体逻辑元素，即 Te 或 Ti） |
| `Fx` | 伦理泛型（未指定具体伦理元素，即 Fe 或 Fi） |
| `Fe/Si (Fe+Si)` | 该现象涉及 Fe 和 Si 的协同作用 |
| `Ti+Se` | 该现象涉及 Ti 和 Se 的协同作用 |
| `Se*` | Se 仅在该现象的特定意义上被使用（见表后注释） |
| `Fe*` | Fe 仅在该现象的特定意义上被使用（见表后注释） |
| `Ne*` | Ne 仅在该现象的特定意义上被使用（见表后注释） |

### 特殊注释

- **Se\***（强项/身体技能）：在 SSS 中，身体技能归属于 Se，但仅指"影响力"方面；强项（strength）作为一个独立概念与 Se 的影响力有所区分
- **Fe\***（恐惧）：在 SSS 中，恐惧被视为 Fe 与情绪控制的结合，而非单纯的 Fe
- **Ne\***（意义之目的）：在 SSS 中，Ne 仅在其作为"意义"（meaning）的语境下被归属于"目的"这一现象

## 主要分歧领域

### 1. 规则与指令：Ti vs Te

这是最大的分歧之一。SCS 将规则、法则和指令归属于**Te**（外倾逻辑），因为它们涉及"外部运动"和"行动方法"。而 SWS、SHS 和 SSS 将其归属于**Ti**（内倾逻辑），认为规则是对象间关系的逻辑系统，而非行动本身。

### 2. 身体外观与美学：Se vs Si

SCS 将身体外观、美学、美丽和服装归属于**Se**（外倾感觉），因为它们涉及"对象的形态"和"动力能量"。而 SWS、SHS 和 SSS 更倾向于将其与**Si**（内倾感觉）关联，认为美学涉及的是对象在空间中对观察者内部状态产生的"回响"。

### 3. 攻击性与力量使用：Te vs Se

SCS 将战斗、攻击性和力量使用归属于**Te**（外倾逻辑），作为"动能的运用"的一个方面。而 SWS、SHS 和 SSS 将其归属于**Se**（外倾感觉），认为是"动力能量"和"意志力"的直接体现。

### 4. 内部内容与结构：Ne vs Ti

SCS 和 SSS 将内部内容与结构归属于**Ne**（外倾直觉），认为它涉及对象"内部内容"的知觉。而 SWS 和 SHS 将其归属于**Ti**（内倾逻辑），认为理解对象的结构是逻辑分析的一部分。

### 5. 节奏与匆忙：Ni vs Te

SCS 和 SSS 将节奏感和匆忙归属于**Ni**（内倾直觉），作为时间感知的一部分。而 SHS 将其与**Te**（外倾逻辑）关联，认为节奏是关于行动的效率和时间安排。

## 如何在实践中使用此表

1. **不要假定共识**：当你阅读不同学派的文献时，同一现象可能被不同的 IME 标签所标记
2. **关注学派上下文**：在分析具体案例时，先确认所使用的学派框架
3. **核心定义优先**：当存在分歧时，回到奥古斯塔的原始定义（参见各 IME 文件的"正式定义"部分）往往是最可靠的参考
4. **功能位置更重要**：对于类型诊断而言，某个 IME 在模型A中的**位置**（主导/创造/脆弱等）比该 IME 涵盖哪些现象更为关键
