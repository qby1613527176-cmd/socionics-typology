# 元素"使用时的心智状态"清单（Mental States When Using Elements）

> 来源：Wikisocion `elements.html`。语料库存 `知乎原文语料/wikisocion_elements_信息元素定义与状态.txt`。
> 本文件收录 8 个信息代谢元素（IME）在**被使用时个体进入的心智状态**——比"话题域"（19-typing-workflow §3.2 速判表）更难伪装的信号层。与 14-scs-indicators 的"内容域→功能速判表"互补但不同层：状态层比话题层更难伪装。
> ⚠️ 心智状态判据属**统计相关**非定义性判据，按规则4当弱-中证据，不进置信度计算。

---

## 一、八个元素的心智状态清单

| IME | 使用时进入的心智状态 | 文本可观察特征 |
|-----|---------------------|---------------|
| **Si** | 身体放松状态、转向当下的连续与流动 | 描述舒适/不适的连续性体验、生活质感、环境和谐 |
| **Ne** | 看见当前情境的潜能、把各种可能提上桌面、重组性游戏、置换、变体、替代方案、解法（包括看似荒谬或不可能的）、信息焕新性对话 | 频繁提出替代方案、引入新可能、"如果……呢"、看见机会与机遇 |
| **Ti** | 分析性心态、思想的清晰与精确、不同结构层面的连贯秩序与规律感、"调试"（debugging）——先看整体系统再找漏洞/错误，或反过来从简单部件构建系统 | 拆解系统、找漏洞、构建因果链、追求逻辑一致性 |
| **Fe** | 从周围动态与他人的行动选择评估情绪与态度、"情绪氛围"的感知力、基于当前可观察反应分析评价他人情绪态度、开放直接表达感受、影响情感与社会空间（通过词与手势的组合） | 评估他人情绪、调控氛围、直接表达感受、用情绪感染他人 |
| **Ni** | 绵长反思的状态、"时间之外"的出神、事后试图补回损失的活动、从记忆中概括抽象过去事件并推断未来走向、反思过去以评估当下可做什么并预测最可能走向、接近不活动的耐心 | 回溯过去推断未来、反思性叙事、因果链推演、等待时机的耐心表述 |
| **Se** | 对自己周围空间与具体环境的意识、外部观察性状态、"现实感"——可触摸也可远在天边的周围一切都被记录、动员状态、对物体与人施力以在空间中移动 | 描述即时现实、外在形态、力量对比、空间占有、意志动员 |
| **Fi** | 分析性状态——分析个人感受与立场、个人价值与情感的和谐/失调、眷恋、亲密、道德满足、情感敏感性、可能产生道德坚定与决心的深层个人信念 | 评估人际关系的吸引/排斥、判断善恶、表达道德立场、描述情感距离 |
| **Te** | 评价性状态——直接从逻辑POV评估他人事件与行动并公开表达、评估产出/效率/有用性/任何投入活动的理性意义、导致不顾当下感受做出理性行动的稳健而有目的的状态 | 评估效率/产出/方法、指导他人工作、区分理性与非理性行动 |

## 二、静/动与外/内倾的"具体表现"（比抽象定义更可直接判读）

### 2.1 静态信息（离散、突变）

| 元素 | 静态时的具体表现 |
|------|----------------|
| Ne | 离散时间阶段与离散替代集 |
| Ti | 事态间离散的逻辑与结构依赖 |
| Se | 界定领地与控制的离散空间边界 |
| Fi | 离散的人际关系类型（如"朋友"或"敌人"） |

### 2.2 动态信息（连续、持续波动）

| 元素 | 动态时的具体表现 |
|------|----------------|
| Si | 与环境的连续物理交换 |
| Fe | 人心理状态的连续激动 |
| Ni | 事物随时间的连续演化 |
| Te | 关于世界的连续客观事实流 |

### 2.3 外倾信息＝"事物本身如何"（独立于其与他者的关系）

| 元素 | 外倾时的判断形式 |
|------|-----------------|
| Ne | 某物**有或没有**潜能 |
| Fe | 某人快乐**或**悲伤 |
| Se | 意识到现实的外部性质**或否** |
| Te | 某物有用**或否** |

### 2.4 内倾信息＝"事物彼此如何关联"（独立于内在性质）

| 元素 | 内倾时的判断形式 |
|------|-----------------|
| Si | X人在Y条件下舒适**或否** |
| Ti | 陈述X是否逻辑上从陈述Y推出 |
| Ni | 事件X是否导致后果Y |
| Fi | X人与Y人关系好**或否** |

> **判型启发**：外倾＝"有无判断"（属性式），内倾＝"关系判断"（关联式）。从文本中提取"此人的判断是属性式还是关联式"，可辅助识别元素态度。
