# 外向感觉 / 力量（Extraverted Sensing — Se）

**符号**：![Se]　　**宏观元素**：感觉　　**态度**：外倾　　**理性/非理性**：非理性　　**静态/动态**：静态　　**显性/隐性**：显性

> 感觉这一宏观元素被定义为<空间>的基础方面，分为外向感觉与内向感觉。该宏观元素关注累计的运动力量、空间中对象的同时交互，以及舒适感和对象形状的特性。

---

## 一、正式定义（两套来源）

### 来源一：奥古斯塔《论人类的二重性》

**动能。** 通过此元素，个体获得关于被观察对象和主体的动员、意志力、力量及美感的信息。

### 来源二：奥古斯塔《socionics中使用符号的含义》

**对象的形态。** 对象的动能，即其释放能量的准备状态。其外在特质——颜色、轮廓、表面光滑或粗糙。外在动员状态。一个人的意志力，以及其在自我和他人身上运用意志的能力和准备程度。

对对象是否准备行使意志、展示力量，以及是否具备审美性的感知。

---

## 二、完整描述

**外向-感知型-非理性-静态-显式**

**对象的形态，对对象外观和形态的知觉。**

动力能量。通过该元素，个体获得关于调动、意志力、强项以及所观察对象和主体的美的信息。

对象的动力能量及其消耗自身能量的准备度。其外部特质：颜色、轮廓、光滑或粗糙的表面，外部调动。个体的意志力，即其在自我及他人身上施展意志的能力与准备度。

判断对象是否准备施展意志、展示力量，以及对象是否具备审美性。

关于我们所称之"动力能量"的对象信息。例如，一个人外在的组织程度、体质及与能量相关的特质、成功施展意志及利用其官方身份的能力。此种知觉使人能够评估个体拥有多少"动力能量"及其在行动中的有效性。它决定了个体是否具备违抗他人意志，并以自身能量对抗他人意志的能力。

当知觉的这一方面占据主导时，个体具备意志品质，是任何新活动的出色组织者。他们倾向于动员他人以实现目标，且懂得如何使用和管理有生命物体与无生命物体。此类个体擅长管理物理事物，例如能够基于现有样本复制几乎任何对象。这体现了他们组织物质的能力。他们寻求发挥自身的意志、能量和力量，以使他人的意志服从于自己。

## 四、符号化定义

**➢ 事物的显性静态 —— 对事物外观的知觉、可见特征、强度（其对感官的影响力）、美感及动机水平。**

**➢ 动力能量。关于被观察事物（包括主体）的动员、意志力、强度和美感的信息。**

---

## 五、关于 Se 的信息

利用此元素，感知到的是关于对象和主体以下方面的信息：

➢ 事物的"动力能量"。例如：某人的外在组织程度、体格及能量相关特质。

➢ 如何处理物理事物，如何基于现有样本再造几乎任何对象。

➢ 一个人的外在组织程度、体质及与能量相关的特质、成功施展意志及利用其官方身份的能力。

➢ 个体拥有多少"动力能量"及其在行动中的效用。

---

## 六、利用此元素，个人可以

当外向感觉（Se）处于主导或创造位置时，个体具备以下核心能力：

➢ 成功施展其意志力，并运用其官方职位。

➢ 观察某人拥有多少"动力能量"及其行动中的效用。

➢ 在与他人意志对抗时发挥意志力，利用自身能量对抗他人能量。

➢ 动员他人为实现目标而努力。

➢ 组织物质——基于现有样本复制几乎任何对象。

➢ 评估谁强谁弱、谁掌控资源、谁意志坚定。

➢ 管理物理事物，包括对无生命物体的熟练操控。

## 七、Se 在不同功能位置的表现

| 位置 | 类型 | Se 的表现 |
|------|------|----------|
| **主导 (1)** | SLE, SEE | 最自觉、最自信的意志力领域。果断、敢于对抗。天生的统治者和组织者。能迅速评估力量平衡并采取行动 |
| **创造 (2)** | LSI, ESI | 创造性地运用力量和意志。在需要时精准施压。以力量和美学作为实现内在秩序和伦理目标的手段 |
| **角色 (3)** | ILE, IEE | 适应社会对外观和力量的期望。表面上试图展示意志力，但不自然。学习"如何看起来有力量" |
| **脆弱/PoLR (4)** | LII, EII | 最薄弱的区域。对意志对抗和物理压力极度敏感。倾向于回避冲突。在需要果断行动的情境中犹豫不决 |
| **暗示 (5)** | IEI, ILI | 完全依赖外部的力量支持。渴望有一个强大的伴侣来保护自己。自身无法果断行动 |
| **激活 (6)** | EIE, LIE | 需要外部鼓励来展现力量。在支持性环境中能显著调动意志力。对外观的批评非常敏感 |
| **观察/忽略 (7)** | SEI, SLI | 能力强但不重视。能在需要时施加力量，但通常选择低调行动。节省资源，避免不必要的冲突 |
| **演示 (8)** | ESE, LSE | 强大且展示性。在必要时刻展现令人惊讶的意志力和动员能力。保护他人时的"爆发性力量" |

## 九、Se 的电荷（±）变体

| 电荷 | 特性 | 所属类型 |
|------|------|---------|
| **Se+（消耗感觉/显性感觉）** | 奢侈花费金钱，投资新事物，将资源视为可自由使用以实现自我充实。将某事物带入注意力中心，使其可见，优雅装扮，活跃于"聚光灯"下 | ILE, SEI, EIE, LSI, SEE, ILI, LSE, EII |
| **Se-（保护感觉/隐形感觉）** | 节约花费，避免在无谓事物上投资，仅在必要时使用资源。将事物移出注意力中心，使其不可见，低调装扮，从"阴影"中运作 | ESE, LII, SLE, IEI, LIE, ESI, IEE, SLI |

**Se+ 的具体表现**：
- 倾向于追求可见性与明晰性，将事物带入聚光灯下
- 关注他人如何提升自身可见性、优雅着装，以及在聚光灯下表现
- 将资源视为可自由利用以实现丰富，将金钱与物质力量作为表达和影响的工具
- SEE 更善于防御，缓解冲突双方的紧张
- LSI 倾向将力量作为防御手段，识别旨在瓦解肇事者抵抗的强制行为

**Se- 的具体表现**：
- 关注物质和物理资源的保存，避免不必要的消耗，除非必要
- 意识到保持隐形、避免不必要关注、穿着朴素、在幕后操作的重要性
- 观察事物如何被移出关注中心，力量和存在感如何被撤回
- SLE 倾向主动攻击，击中薄弱点，消灭弱者
- ESI 最初表现出压力，推动个体采取特定行动

## 十、在模型G中的对应

在古连科的模型G / SHS 学派中，Se 的电荷分为：

- **F+（通过抵抗感受力量）**：组建联盟以击败更强的敌人。拥抱力量。维持平衡，寻找盟友，自我防卫，最大化力量。必要的防御力量，当他们能说这不是他们的错，是被先攻击或别无选择只得使用力量时使用。SEE 更善于防御，缓解冲突双方的紧张。LSI 倾向将力量作为防御手段，识别旨在瓦解肇事者抵抗的强制行为。

- **F-（通过顺从感受力量）**：挟持人质，使他人依赖于你。建立并尊重强者对弱者的等级，极力轻视和蔑视妨碍的弱点。压制性的力量，主动攻击，实际或比喻地掌控事物，公开展现力量，从他人口中夺取他们未善用的东西。比较性、攻击性、威胁性，贬低弱点。SLE 倾向主动攻击，击中薄弱点，消灭弱者。ESI 最初表现出压力，推动个体采取特定行动。

## 十一、Se 与其他 IME 的关联

### Se 与 Si（内倾感觉）

Se 关注的是对象**外在的**、**可被施加的**力量和形态；Si 关注的是对象**内部的**感受状态及空间中同时发生的交互关系。Se 是"征服空间"，Si 是"在空间中感到舒适"。

### Se 与 Ne（外倾直觉）

Se 关注对象**当前的**、**可见的**动力能量和意志力；Ne 关注对象**潜在的**、**隐藏的**内部能力和可能性。Se 是"此时此地我能做什么"，Ne 是"未来可能实现什么"。

### Se 与 Te（外倾逻辑）

Se 感知力量和意志的准备状态；Te 将这些力量和意志转化为**具体的行动、工作和效率**。Se 是"我准备好了"，Te 是"我做到了"。

### Se 与 Fi（内倾伦理）

在 Gamma Quadra（SEE, ILI, LIE, ESI）中，Se 与 Fi 协作——力量用于建立和维护基于个人伦理判断的关系边界；在 Beta Quadra（EIE, LSI, SLE, IEI）中，Se 与 Ti 协作——力量用于构建和维护等级系统和组织结构。
