# 模型G（古连科能量模型）——导航与概览

本目录包含维克多·古连科（Victor Gulenko）创立的**模型G**（也称能量模型G、SHS模型）的完整理论文档。模型G是人文Socionics学派（SHS）的核心框架——它以能量代谢为基础，重新组织了八个功能位置，使其更符合"完成的工作量"而非"信息的感知与处理"。模型G并不否定模型A，而是将其与能量-信息代谢（EIM）的统一模型整合。

## 什么是模型G？

模型G是维克多·古连科在奥古斯塔的模型A基础上发展出的**能量模型**。它的核心创新在于：

1. **以能量代谢为核心**：模型G追踪信息**与能量**的流动——能量涉及类型执行工作（物理意义上的工作）的能力及其对某些方面输出有形且可见影响的能力

2. **重新排列功能位置**：八个功能在模型G中的位置与模型A完全不同。例如，模型A的创造功能（A2）在模型G中对应演示功能（G5），而模型G的创造功能（G2）对应模型A的演示功能（A8）

3. **四个能量层级**：模型G将八功能组织为四组垂直能量层级——最大能量（G1+G5）、最优能量（G2+G6）、最小能量（G3+G7）、最差能量（G4+G8）——每组代表不同的能量输出能力和使用效率

4. **两个维度的四组水平块**：外部性（社会层面：社会使命块+社会适应块）和内部性（个人层面：自我确认块+通货膨胀避免块）

## 模型G结构速查

### 水平块总览

| 层面 | 块名称 | 位置 | 核心功能 |
|------|--------|------|---------|
| **外部性**（社会） | 社会使命块 | G1 + G2 | 最强大。自信的社会自我实现。领导者块 |
| **外部性**（社会） | 社会适应块 | G3 + G4 | 解决常规任务。生存机制。通过培训改善 |
| **内部性**（个人） | 自我确认块 | G5 + G6 | 个人创造空间。演示和操控。自发但不持续 |
| **内部性**（个人） | 通货膨胀避免块 | G7 + G8 | 最弱。消耗大量能量。炎症效应。需要保护 |

### 垂直块（能量层级）总览

| 能量层级 | 位置 | 能量特征 | 核心角色 |
|---------|------|---------|---------|
| **最大能量** | G1 + G5 | 能量过剩，持续运作，难以关闭 | 社会扩张的引擎 |
| **最优能量** | G2 + G6 | 按需启动，能量使用最"经济" | 解决实际问题的工具 |
| **最小能量** | G3 + G7 | 能量有限，适合重复简单的常规任务 | "节能模式" |
| **最差能量** | G4 + G8 | 能量极度匮乏，仅能短暂运作 | "点火"和"求助"系统 |

### 能量功能层级（1D-4D能量）

| 能量维度 | 对应位置 | 能力描述 |
|---------|---------|---------|
| **4D能量** | G1, G5 | 当前灵活调节 + 未来战略规划 + 长期能量储备 |
| **3D能量** | G2, G6 | 当前灵活调节。按任务需求投入不同能量。最"经济" |
| **2D能量** | G3, G7 | 可开关但不可精细调节。适合常规任务 |
| **1D能量** | G4, G8 | 仅能被激活或放松。无法主动控制。被动反应性 |

## 七组功能二分法速查

| # | 二分法 | 决定因素 | 核心问题 |
|---|--------|---------|---------|
| 1 | **运动 / 潜能** | 类型的静态/动态 | 功能是消耗能量行动还是积累信息表达？ |
| 2 | **稳定 / 不稳定** | 类型的理性/非理性 | 功能是持续一致运作还是需要动机激发？ |
| 3 | **主导 / 奴役** | 类型的主要态度 | 功能是发起能量脉冲还是接收脉冲？ |
| 4 | **加速 / 减速** | Quadra价值观 | 功能是提升能量还是消耗能量？ |
| 5 | **自动 / 有意识** | 功能在模型G中的位置 | 功能是无意识自动运行还是有意识主动调用？ |
| 6 | **价值 / 工具** | Quadra价值观 + 功能配对 | 功能提供长期动机（why）还是解决具体问题（how）？ |
| 7 | **公开 / 私密** | 类型的外倾/内倾 | 功能在大群体中使用还是仅在亲密环境中显现？ |

## 模型A与模型G的核心差异速查

| 维度 | 模型A（奥古斯塔） | 模型G（古连科） |
|------|-----------------|----------------|
| **核心关注** | 信息流动——信息如何被感知、处理、传递 | 能量与信息流动——能量如何输出信息（新的秩序、宝贵的经验、既定的知识） |
| **方法论** | 类型学方法。基于偏好和自我描述。构建确定性系统 | 整体论方法。考虑所有可能的因素：动作、说话、行为、职业、群体角色。类型是"较好匹配" |
| **类型匹配度** | 追求精确匹配 | 60%-90%匹配度。类型内部变异极大（亚型、性格特征、活动方向转变） |
| **功能位置** | 八功能按模型A排列。类型由自我块（A1+A2）定义 | 八功能按模型G排列。类型由社会使命块（G1+G2）定义 |
| **能量理论** | 信息和能量代谢的阶段和半阶段 | 四个能量层级（最大/最优/最小/最差）。能量功能1D-4D |
| **亚型系统** | 终端/初始亚型。部分使用DCNH | DCNH四亚型为核心。亚型显著影响自我认知 |
| **电荷系统** | 奥古斯塔三套电荷系统。电荷由进化/内卷决定 | SHS电荷系统。电荷由模型G能量层级+能量代谢方向+社会使命角色+Quadra归属四因素综合决定 |
