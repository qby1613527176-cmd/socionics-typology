# 塔拉诺夫行为标记库与成对差分工具（Type Markers & Paired Differential Diagnosis）

> 来源：sociotype.xyz/m/*（Original Source: V. L. Talanov）；中文译文见余音 p/3979909983（ILE）、p/4114934977（合集）。语料库存 `/workspace/06_socionics分析/知乎原文语料/TypeMarkers_{ILE/ESI/ILI}_全文.txt`。
> 站点自述：markers 是 **"the most distinctive behavioral markers of 16 types"**，用于 **"differential diagnosis between two types, not for diagnosing each type individually based on only one half of the scale"**。
> ⚠️ **使用纪律（最高优先级）**：markers 是塔拉诺夫问卷聚类的**统计区分特征**，非定义性判据；**单边命中不得定案**——站点已声明"不可只用半边定案"。与本库规则4（禁止单题定音）、规则16（高自由参数计分过拟合）一致。markers 不进入置信度计算。

## 一、为什么需要本文件

19-typing-workflow 规则17 要求"镜像假设强制全建"——对主候选与其冲突对/镜像候选**以同等成本完整构建读法**。但规则17只规定"要建"，未提供**差分工具**。既往判型事故（去标识）复盘显示：若当时对镜像候选对跑过 markers 成对差分，大量条目会亮红灯（保守/反新异/反讽缺失/不擅哲学化），可阻止误判。

本文件提供两类工具：
1. **markers 清单**（按信道分层；2026-09-04 已抓全16型页面，其中7型逐条全文归档、9型按文本高区分项与面判/生理项精选归档）
2. **成对差分表**（A vs B 取"更具备"条目 → 判"支持A/支持B/两者皆可"）

## 二、markers 的信道分层

塔拉诺夫 markers 多为**可外部观察的具体行为/生理测量项**（咬牙、笔迹、饮水量、睡眠、心率、脑叶活动），与奥什拉/古连科的"心理结构描述"不同层。

| 信道 | 可用项举例 | 判型效力 |
|------|-----------|---------|
| **文本可用** | 自创新词(neologisms)、混淆日期、音韵错误、对"血亲之声"的态度、对权威/意识形态的态度、对新异的渴求、对多样性的偏好 | 文本判型可引，但属**统计相关**非定义 |
| **面判/视频专用** | 笔迹大小/工整度、饮水/咖啡量、睡眠需求、眼球运动、语速、步态、无意识运动(咬牙/吸吮/踱步) | 文本永远拿不到；行为探针/线下信道可用 |
| **临床降权** | 述情障碍、快感缺失、意志缺乏、脑叶活动、心率(心动过速/过缓)、黏膜干燥 | 作者统计相关，**不得当判型定义**；引用需标注"临床断言降权" |

> **九A信道表对接**：markers 属"视频/线下信道"行的判据来源；文本判型只能采"文本可用"子集，且按规则4当弱证据。

## 三、已收三型 markers 清单（ILE / ESI / ILI）

### 3.1 ILE（探索者）markers（131条，全文存语料）

**文本可用高区分条目（精选）**：
- 持续渴求新异与变化，对新事物与创新高度兴趣（#1,2）
- 偏好多选项情境，热爱多样性与最大选择自由（#3,19）
- 冲动且常冒险，偏好革命性变化而非静止（#5）
- 对自己与严肃事务有幽默感（#6）
- 独立大胆，不依赖领导者或权威（#7）
- 行为较他人更无政府主义，常无视社会规范与禁令（#8）
- 难以正确感知他人的敌意信号（#9）
- 重视颠覆胜过稳定，乐于扰乱或目睹秩序被扰乱（#12）
- 否认"血亲之声"概念（#14）
- 常混淆当前月份/日期/星期（#15）
- 倾向半波希米亚生活方式，缺乏家庭完美主义（#17）
- 偏爱个体天赋胜过集体结构（#18）
- 常偏离计划、迟到、错过截止日（#21）
- 喜欢惊喜与不可预测（#22）
- 常"逆流而行"，敢于独抗多数或权威（#24）
- 言语中常自创新词（#26）

**面判/生理项**：常咬牙/叩齿(#10)、语音错误(#20)、需睡眠少且日间少困(#23)、日饮水量偏多(#25)。

### 3.2 ESI（守护者）markers（131条，全文存语料）

**文本可用高区分条目（精选）**：
- 在关系中远虑、谨慎、多疑（#1）
- 厌恶变化与创新，偏好熟悉与已验证方法（#2,15,29,34,67,101,110）
- 对群体内关系性质始终确信（#3）
- 对社会与道德规范违反高度反应（#4）
- 对他人关系与行为细节高度观察与记忆（#5）
- 要求他人严格遵守社会规范（#7）
- 敏感于敌意信号（#13）
- 拒用新词，言语精确克制（#16）
- 感知自我与他者清晰边界（#17）
- 难以产生新观念，缺乏宏大理念，不关注深层智性问题，不好奇（#19,50,52,54,114）
- 重视完成胜过开启，道德行为保守（#26,31,20）
- 缺乏反讽与幽默技巧，不能容忍对严肃事的玩笑，很少公开笑，隐喻理解困难（#40,56,107,120）
- 喜欢整数与清晰边界，厌恶模糊（#55）
- 对新环境常焦虑"力不从心"（#71）
- 想象世界为静态图像而非流动（#75,125）
- 偏好字面思维胜过概率思维（#115）
- 时间感知均匀流动（#118）
- 忠诚与忠实高于一切（#63,122）

**面判/生理项**：笔迹小或中且工整(#22,89)、日饮水量偏少(#25)、需更多更深睡眠(#58)、无踱步(#33)、无神经性抽动(#64)、高度恐高(#72)、无偷窃癖(#74)、心率倾向心动过速(#106)。

### 3.3 ILI（批评者）markers（161条，全文存语料）

**文本可用高区分条目（精选）**：
- 他人的在场与参与比独处更令人不适（#26）
- 厌恶讨论或介入他人私事（#27）
- 他人受伤时通常冷静，提供帮助但无明显痛苦（#28）
- 常感无聊，视生活平庸无趣（#29）
- 缺乏强烈快乐或愉悦感，回避深度对话（#30）
- 很少与朋友分享个人情感经历（#32）
- 对个人着装少有关注（#33）
- 常面容严肃，少笑或回应幽默（#34）
- 常批评或警示他人而面无表情（#35）
- 节约能量，吝于使用身体与情感资源（#37）
- 几无情绪热情或感染力（#38）
- 避免目光接触（#39）
- 不善社交、略反社会（#41）
- 预见性与前瞻思维（#40）
- 以实用与功能为导向，避免一切无用活动（#48,……）

**面判/生理项**：黏膜干燥倾向(#36)、无踱步/无意识运动、笔迹特征、心率等（详见语料）。

## 四、成对差分表工具（规则17的落地工具）

> **操作流程**（对主候选 X 与其冲突对/镜像 X′ 各执行一次）：
> 1. 列出 X 与 X′ 的 markers 全清单
> 2. 逐条取"X 更具备 / X′ 更具备 / 两者皆可"三态
> 3. **"两者皆可"条目作废**（无区分度）
> 4. 计 X 支持数 vs X′ 支持数；差值≥决定性级阈值才允许单假设输出，否则双假设
> 5. **禁止单边命中率计分**（Wikisocion diagnosis 警告：对叙事描述做单边命中=Barnum 高发）

#### 4.3 差分表操作流程（补充）

> **使用纪律**：markers 是**统计区分特征**（塔拉诺夫问卷聚类），不是定义性判据。差分表结果**不进入置信度计算**，只作规则17镜像全建的"定性对照清单"。

1. **确定差分对**：主候选 X + 镜像 X′（冲突对/镜像对/准同一等）
2. **逐条三态判定**：X 更具备 / X′ 更具备 / 两者皆可
3. **作废"两者皆可"条目**
4. **计数与判定**：
   - X支持数 ≥ 2×X′支持数 且 X′支持数 ≤ 2 → 强支持X（但仍需SCS层证据）
   - 两者相当 → 双假设
   - X′显著多于X → 翻案信号，重开全案
5. **禁令**：不得仅凭差分表单边计数定案（规则4）；不得仅对主假设运行（规则17要求含镜像）；差分结果不进置信度（规则10）

#### 4.4 对偶对差分（v5.12新增·配置9 复盘落地）

> **背景**：配置9（对偶偏移）复盘显示——文字判型的方向可能系统性滑向答卷人自判类型的**对偶/激活方**（未二元化＋低谷期答卷的超本我话语＝对偶自我块话语，被误读为本人主导）。为此，对偶对差分须与冲突对/镜像对（4.1/4.2）**同权**使用：凡文本方向与某候选的对偶端重合，按规则28/31/R0.9 强制执行。
> **使用纪律同 4.3**：差分结果不进置信度（规则10）、不得单边定案（规则4）、须镜像/对偶双侧同跑（规则17）。

**SEE vs ILI（对偶对·本次事故核心；其余对偶对方法同此表）**

| 维度 | SEE 倾向 | ILI 倾向 | 区分度 |
