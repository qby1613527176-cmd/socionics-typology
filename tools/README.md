# 判型工具集（tools/）——v6.0.2 可执行资产

> 本目录是判型流程的**可执行资产**，随 skill 整体移植与备份（N9 覆盖）。
> 判型会话中的"实例数据"（判型日志、校准记录、杀手题文件）由本目录脚本生成到用户指定/工作区路径——
> 脚本在 skill 内，数据在工作区：脚本移植、数据隔离。

## 脚本清单

| 脚本 | 用途 | 对应条款 | 生成物 |
|------|------|---------|--------|
| `start-typing-log.sh` | 判型会话日志闸门：创建卷日志文件、登记启动信息 | §三十二·二六 | /workspace/session-audit/<卷名>.json |
| `probe-init.sh` | R0.7-G 杀手题文件闸门：初始化杀手题文件 | §三十二·一 | /workspace/session-probes-<卷名>.md |
| `lang-scan.sh` | 语言纪律机械扫描（L1-L2.1 每单元执行） | §三十二·四 | 扫描结果（空/命中行） |
| `line-refresh.sh` | 行号速查表刷新/校验（§三十一·三） | §三十一·〇/三 | 行号漂移报告 |
| `ck-report.sh` | CK 输出物证生成（命令回显提取） | R0.3 CK 四列 | CK 物证块 |
| `calib-append.sh` | 校准+预测回访记录追加 | §三十二·二四/规则65 | /workspace/calibration-log.md |
| `dual-sample.sh` | 分歧强制双采样（规则34 子条款） | §三十二·二七 | /workspace/判型日志/<卷名>-sampling.json |

> **使用纪律**：脚本由 19 号流程文档条款引用调用，不可由判型器"凭记忆"替代；输出物证须贴入回复（R0.2-d 物证精神）。
