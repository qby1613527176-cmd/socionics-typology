# model-t — 塔拉诺夫学派经验画像（16 TIM）

> **架构定位**：与 `model-a`（奥古斯塔/韦斯班德）、`model-g`（古连科）平行的第三个类型描述集，来源为 V. Talanov 学派的经验画像（问卷统计与心理测量学取向）。文件体量与 `model-g` 相当（每型约2K）。
>
> **必读前置**：`references/20-talanov-notes.md`——该学派与奥古斯塔/SCS体系**同名不同义**（±符号、部分二分法），临床断言不可作判据，跨学派画像存在内部分歧（典型如ESI）。

## 使用纪律（摘要，详见20号文件）

1. **学派归属强制标注**：引用本目录画像时必须注明"塔氏画像"，不得与奥什拉/古连科描述混排成单一"类型事实"。
2. **画像分歧双读**：同一TIM在塔氏与奥什拉/古连科画像下行为层结论可能不同（ESI：塔氏"保守守规矩" vs 奥什拉"反叛式疏远"）。Layer 7比对时双读并注明，不得只用其中一支。
3. **可靠性分层**：原型定位/行为倾向可用；临床断言（成瘾、解体、人格障碍相关、压力生理反应等）一律降权为倾向参考，不作判据。
4. **不得进打分流程**：本目录不提供维度/电荷/位置判据，仅作Layer 7跨学派比对与探针设计素材。塔氏±体系与Qi/Qe/Di/De二分法的限制见20号文件§1–2。
5. **二分法归属不全**：Qi/Qe/Di/De每极仅2个示例类型有原文依据，多数类型归属系由画像推断（标注"未标注"者不推断）。
